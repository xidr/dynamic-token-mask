# Model calibration

**TL;DR:** Append one row per finished task in the builder tool’s log.

Last verified: 2026-11-23

- [[topics/model-calibration/codex]] covers CLI and native builders.
- [[topics/model-calibration/gemini]] covers Gemini Swarm.

Record date, task, kind, planner, builder and batch count, actual reviewer and verdict, fix rounds, findings and optional rough cost notes. Skip private billing or account data. Log cross-tool reviews under the builder. Compare similar tasks: repeated rework supports moving up a tier, and consistently clean reviews support trying a lighter tier.
